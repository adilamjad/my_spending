⚙️ Android Automation Setup

Connect your Android phone using MacroDroid so bank SMS alerts automatically sync into this app.

1. Install MacroDroid (Free)

Download MacroDroid - Device Automation from the Google Play Store on your Android phone.

2. Create a Macro in MacroDroid
A. Trigger:
Tap + Trigger → Messaging → SMS Received → Select sender (e.g., ALRAJHI, SNB, RIYAD, or Any).
B. Action:
Tap + Action → Connectivity → HTTP Request / Web Request:
  • Request Method: POST
  • Content Type: application/json
https://firestore.googleapis.com/v1/projects/spending-tracker-6db2d/databases/(default)/documents/households/family_default/pending_sms?key=AIzaSyCZV_am4fczF_wwHI8XtZKepX7uS8kBLl8
{ "fields": { "text": {"stringValue": "{sms_message}"}, "sender": {"stringValue": "{sms_number}"}, "receivedAt": {"stringValue": "{year}-{month_digit}-{day_digit} {hour_24}:{minute}"}, "spentBy": {"stringValue": "dad"} } }
💡 Tip: Change "dad" to "mom" or "son" depending on whose phone MacroDroid is installed on!
